# Inverse compiler

Status: **pending** (Phases I–N). This document will specify the hierarchical
"unbaking" pipeline when the compiler lands.

Planned architecture (paper §Inverse Proceduralization):

1. source characterization;
2. exact structural reuse (hashing repeated patches/spans);
3. palette/index discovery;
4. translation/repetition/affine reuse;
5. symmetry/periodicity;
6. simple analytic families;
7. seeded procedural fields;
8. compound/hierarchical factors;
9. residual decomposition;
10. literal/original fallback.

Search is Pareto-first (persistent bytes, residual bytes, search time,
materialization time, memory), with a bounded factorization tree, DSFB as a
zero-authority governor only, and regret courts against exhaustive search on
small candidate universes.
